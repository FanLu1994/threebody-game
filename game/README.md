# 三体 · 红岸纪事（3D 互动游戏）

基于刘慈欣《三体》三部曲第一部改编的**同人 3D 互动游戏**。单机网页游戏，无构建步骤、无外部素材——所有模型、贴图、音效均为程序化生成。

## 运行方式

**方式一（推荐）**：启动本地服务器后用浏览器打开

```
cd game
python server.py 8641        # 或：python -m http.server 8641
# 浏览器访问 http://localhost:8641/
```

**方式二**：直接双击 `game/index.html`（游戏不依赖任何网络请求，file:// 协议可玩）

需要支持 WebGL 的现代浏览器（Chrome / Edge / Firefox 均可）。

## 章节与玩法

| 章节 | 剧情 | 玩法 |
|------|------|------|
| 序章 · 疯狂年代 | 1967—1969，叶文洁的绝望之源 | 叙事过场 |
| 第一章 · 红岸 | 雷达峰绝密基地，太阳增益发射 | **拖动画面校准天线对准太阳**，增益锁定后发射；八年后收到警告，做出改变人类命运的选择 |
| 第二章 · 乱纪元 | 还原书中"三体"VR游戏 | **观测飞星数量**判断天象（三颗飞星=长夜、飞星不动=巨日将至），在酷热与严寒中及时**脱水/浸泡**，带领文明活过七个昼夜，直面三日凌空 |
| 第三章 · 人列计算机 | 秦始皇三千万大军组成的计算机 | 你是一名门电路士兵：根据输入旗色（黑=1 白=0）按与/或/非/异或规则举旗，答错三次全军死锁；通关后观看"秦一号"运算与三日连珠 |
| 第四章 · 古筝行动 | 巴拿马运河，纳米丝切割"审判日"号 | 在巨轮恰好压住切割面时**收紧纳米丝**——太早丝断，太晚数据被毁；成功后观看整船切片 |
| 终章 · 虫子与舰队 | 华北蝗灾的启示与三体舰队启航 | 叙事 + 450年倒计时 |

## 操作

- 点击 / 空格 / 回车：推进对话
- 第一章：按住鼠标拖动 = 转动天线
- 第三章：点击按钮或按键盘 `0` / `1` 举旗；演出中按 `Esc` 跳过
- 进度自动保存在浏览器 localStorage（章节选择可重玩已解锁章节）

## 技术说明

- 引擎：Three.js r128（本地 `lib/three.min.js`）
- 代码结构：`js/engine.js`（渲染/UI/音频/时间线核心）、`js/ch0—ch5_*.js`（六个章节）、`js/main.js`（菜单与章节流）
- 音效：WebAudio 实时合成；贴图：Canvas 程序化绘制
- 大规模物件（秦军方阵、麦田、舰队）使用 InstancedMesh 实例化渲染
- `test/run_test.js`：playwright-core + 无头 Edge 的全流程自动化回归测试（约 400 秒通关全六章并截图）
