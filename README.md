# 三体 · 红岸纪事（3D 互动游戏）

基于刘慈欣《三体》三部曲第一部改编的**同人 3D 网页游戏**。Three.js 渲染、全程序化生成素材、零构建步骤。

> 本仓库不含小说原文。游戏为粉丝同人作品，旁白与对白均为原创改写，详见 [game/README.md](game/README.md)。

## 在线游玩

部署在 Vercel：**https://threebody-game.vercel.app/**

## 本地运行

```bash
cd game
python server.py 8641      # 或任意静态服务器
# 打开 http://localhost:8641/
```

也可以直接双击 `game/index.html`（无任何网络依赖）。

## 目录结构

- `game/` —— 游戏本体（引擎、六个章节、菜单）
- `test/` —— playwright-core 自动化测试（全流程回归 + 乱点压力测试）

## 章节一览

| 章节 | 玩法 |
|------|------|
| 序章 · 疯狂年代 | 叙事 |
| 第一章 · 红岸 | 天线校准 → 太阳增益发射 → 抉择 |
| 第二章 · 乱纪元 | 观飞星、脱水/浸泡生存 |
| 第三章 · 人列计算机 | 与/或/非/异或逻辑门答题 |
| 第四章 · 古筝行动 | 纳米丝切割时机 |
| 终章 · 虫子与舰队 | 叙事 + 450年倒计时 |
